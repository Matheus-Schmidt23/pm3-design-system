# PM3 — Design System

Design system da PM3 baseado no Key Visual 2025: cores, tipografia, logo, grid fluido, componentes, peças de referência, tokens e tom de voz.

## Arquivos

| Arquivo | O que é |
|---|---|
| `Design-System-PM3.html` | Guia web completo, **autossuficiente** (imagens embutidas) e com tela de login. Abra direto no navegador. |
| `Design-System-PM3.pdf` | Versão em PDF, 16:9 (1920 × 1080), 22 slides. |
| `Design-System-PM3-16x9.html` | Fonte dos slides do PDF (usa a pasta `assets/`). |
| `Design-System-PM3.fonte.html` | Fonte editável do guia web (usa a pasta `assets/`). |
| `assets/` | Logos (SVG), fotos e texturas usadas pelos arquivos-fonte. |

## Observações

- O login do guia web roda no navegador e é só uma barreira leve; não substitui autenticação de servidor.
- As imagens são de duas origens: arquivos gerados por IA e arquivos de banco de imagens (Shutterstock). Confirme os direitos de uso antes de publicar peças externas.
- Fontes carregadas do Google Fonts: Inter Tight, Rubik e Playfair Display.
